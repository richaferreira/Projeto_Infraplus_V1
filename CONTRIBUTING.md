🛠️ Como contribuir para o InfraPlus
Primeiramente, obrigado por se interessar em ajudar no InfraPlus! Este projeto visa melhorar a gestão de infraestrutura de água e sua ajuda é fundamental.

🚀 Como começar?
Encontre uma Issue: Procure por tarefas marcadas com a label good first issue no nosso repositório.

Faça um Fork: Crie uma cópia do projeto na sua conta do GitHub.

Crie sua Branch: Use nomes descritivos, por exemplo: git checkout -b feature/validacao-formulario.

💻 Padrões de Código
Como utilizamos Python e Flask, pedimos que siga algumas boas práticas:

PEP 8: Tente manter o código seguindo os padrões de estilo do Python.

Comentários: Adicione comentários em partes complexas do código, especialmente nas rotas e modelos de dados.

Commits: Escreva mensagens de commit claras e em português (ex: "Adiciona validação de campo obrigatório").

📬 Enviando sua contribuição
Após finalizar, faça o Push da sua branch e abra um Pull Request.

Descreva brevemente o que você alterou e qual Issue está resolvendo.

Aguarde a revisão! Como estou estudando essas tecnologias, ficarei feliz em trocar conhecimentos durante o review.
